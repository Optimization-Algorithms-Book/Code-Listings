About the book

From toy problems to real-world solutions

Optimization is everywhere: in how ants find food, how parcels are routed, how airlines schedule crews and how cities manage traffic. Most real problems are ill-structured: large, dynamic, uncertain and without a neat mathematical model, so classic derivative-based solvers struggle. This book covers the algorithms built for them.

It moves from deterministic graph search (blind and informed) to trajectory-based methods (simulated annealing and tabu search), evolutionary computing (genetic algorithms and their variants), swarm intelligence (particle swarm and ant colony optimization) and finally machine learning (supervised, unsupervised and reinforcement learning applied to optimization). Along the way it tackles routing, scheduling, assignment, packing, districting, control and many more design, planning and control problems.

Every chapter has Python notebooks in the book’s GitHub repository, ready to run in Google Colab, and an interactive lab to explore in the browser.

Fire Mountain is the highest point on the island, but it is an active volcano, so it can never be the answer. This is why constraints matter: the best feasible solution is not always the highest point overall.
