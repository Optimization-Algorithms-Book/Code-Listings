# Optimization Algorithms: AI techniques for design, planning, and control problems

> ### 🌐 [Visit the book’s website](https://optimization-algorithms-book.github.io/Code-Listings/)

<a href="https://www.manning.com/books/optimization-algorithms">
<img src="images/Khamis.jpg" alt="Optimization Algorithms: AI techniques for design, planning, and control problems" width="260" align="right"></a>

This book is written for practitioners interested in solving ill-structured search and optimization problems using modern derivative-free algorithms. It will get you up to speed with the core concepts of search and optimization and give you the ability to handle practical design, planning and control problems.

Without assuming any prior knowledge of search and optimization, and with only an intermediate knowledge of data structures and Python, this book is designed to take anyone from never having solved search and optimization problems to being a well-rounded practitioner. You will be able to select, implement, and adapt the right solver for the right problem.

**At a glance:** 5 parts · 12 chapters · 3 appendices · 136 Python notebooks · 13 interactive labs

## 🚀 Getting started

- **In the browser:** open any notebook in its chapter folder and click the **Open in Colab** badge; nothing to install.
- **On your machine:** clone the repository and install the dependencies, including the book’s helper package `optalgotools`:
  ```bash
  git clone https://github.com/Optimization-Algorithms-Book/Code-Listings.git
  cd Code-Listings
  pip install -r requirements.txt
  ```

> **Note:** If you downloaded the code bundle from the Manning website, check this [official repository](https://github.com/Optimization-Algorithms-Book/Code-Listings) for the most recent version.
