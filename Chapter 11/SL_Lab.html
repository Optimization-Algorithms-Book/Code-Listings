Part 1 · Section 11.2

Supervised learning

Supervised learning approximates a mapping between data and known labels from N training examples (x1, …, xm, c). Classification predicts discrete classes with a scoring function f: X × C → ℝ and c(x) = argmaxc f(x, c); regression predicts continuous values. A self-driving car learns to recognize traffic signs from labeled images. Common architectures: feedforward networks (MLPs), convolutional (CNN), recurrent (RNN, LSTM) and sequence-to-sequence models.

Deep learning stacks many layers to learn features at several levels of abstraction directly from raw data, and geometric deep learning extends it to non-Euclidean data such as graphs, point clouds and manifolds.

Part 2 · Neural networks

Training a neural network

A multilayer perceptron transforms its input through layers of weighted sums and nonlinear activations. Training is optimization: backpropagation computes the gradient of the loss (here, cross-entropy) with respect to every weight, and a gradient method (here, Adam) moves the weights downhill. ReLU, max(0, z), is the usual activation; LeakyReLU keeps a small slope for z < 0 so neurons never “die,” and GAT uses it in its attention scores. Points are split 75/25 into training and test sets.

Part 3 · Section 11.3

Machine learning with graphs

Graphs capture relationships: social networks, road networks, the web, knowledge graphs, molecules. Tabular data can be turned into a graph by choosing what the nodes and edges are. Listing 11.1 links 10 soccer players to their clubs (“plays_for”) and nationalities (“belongs_to”), giving 30 nodes and 20 edges.

Graph data is non-Euclidean: closeness comes from connections, not coordinates; there is no fixed grid, no shift-invariance, and no node order (permutation invariance). Graph embedding maps each node to a low-dimensional vector so that nodes similar in the graph are close in the embedding space. Transductive methods (DeepWalk, node2vec, matrix factorization) embed only the nodes seen in training; inductive ones (GNN, GCN) learn a function that also embeds new nodes.

Message passing and graph convolution

In a graph convolutional network, each layer lets every node gather messages from its neighbors, aggregate them with a permutation-invariant function (sum or mean), and update its own state (Figures 11.6 and 11.7). In matrix form, H(t+1) = σ(Â H(t) W(t)), with Â = D−1/2(A + I)D−1/2: A is the adjacency matrix, I adds self-loops so a node keeps its own features, and the degree matrix D normalizes so features do not explode. After k layers, a node’s embedding encodes its k-hop neighborhood.

Google DeepMind used this idea to predict arrival times: road segments become nodes, so traffic on one segment informs its neighbors, improving real-time ETA accuracy by up to 50% in several cities.

Part 4 · Section 11.3.2

Attention

A GCN gives every neighbor the same learned weight. Attention lets a model decide how much each input matters. A graph attention network (GAT) scores each neighbor u of node v, evu = a(W hv, W hu) (equation 11.1), and normalizes the scores with a softmax, αvu = exp(evu) / Σk∈N(v) exp(evk) (equation 11.2). With multi-head attention, several independent heads attend in different ways and their results are averaged (Figure 11.10).

The Transformer (“Attention is all you need”) applies the same idea to sequences: a query q is compared with every key kᵢ, the softmax of the scores weights the values vᵢ, and the output is Σ αᵢ vᵢ. This fixes the forgetting problem of reading long sequences word by word.

Part 5 · Sections 11.3.3 and 11.9

Pointer networks and the convex hull

Sequence-to-sequence models map one sequence to another, but in problems like the TSP, sorting or the convex hull, the outputs are positions in the input, so the output dictionary changes with the input length. A pointer network (Ptr-Net) uses attention as a pointer: at each decoding step, a softmax over the encoder states, aᵢ = softmax(vᵀ tanh(W₁eⱼ + W₂dᵢ)) (equations 11.3 to 11.5), picks the input element to output next, until an end token.

The convex hull is the smallest convex polygon enclosing all the points: maximum area with minimum perimeter. Classic algorithms include the Graham scan, the Jarvis march (gift wrapping) and quickhull; they provide the training targets. The book’s transformer-based ConvexNet reaches about 96.5% validation accuracy; on test sets its accuracy and hull overlap vary with the number of points:

Part 6 · Section 11.7

Solving the TSP with supervised graph ML

Joshi, Laurent and Bresson’s pipeline (Figure 11.16) has five steps. Data: describe the problem as a graph. Embed: compute node and edge representations by message passing. Predict: an MLP gives each edge a probability of belonging to the optimal tour. Search: decode a feasible tour greedily or with beam search (Chapter 4). Train: learn by imitating optimal tours from the Concorde solver (supervised) or by reinforcement. Listing 11.4 runs a pretrained model on TSP20 to TSP50 instances. Here the “predict” step is a stand-in that scores each edge by a softmax over a city’s nearest neighbors, so the search step can be explored on its own.

Part 7 · Section 11.6

Amortized optimization: learning to optimize

When the same kind of optimization problem is solved again and again, a model can learn to map a problem’s parameters directly to its solution. Training is costly, but each new problem then takes one quick forward pass: the cost is amortized. Listing 11.3 does this on the sphere: “c-convex” functions built from 4 components (soft-min of 0.5·d(y, yₖ)² + αₖ) are parameterized by their centers and offsets, and an MLP is trained to output the minimizer, using f(model(p)) itself as the loss.

This lab uses the circle instead of the sphere, so each function can be drawn. Train the model on 64 random problems, then test it on problems it has never seen.

# A multilayer perceptron trained by backpropagation and gradient descent (supervised classification)
import numpy as np

rng = np.random.default_rng(0)
t = rng.uniform(0, np.pi, 200)
X = np.vstack([np.c_[np.cos(t), np.sin(t)], np.c_[1 - np.cos(t), 0.5 - np.sin(t)]]) + 0.1 * rng.standard_normal((400, 2))
y = np.repeat([0, 1], 200)
idx = rng.permutation(400); train, test = idx[:300], idx[300:]

H = 16
W1, b1 = rng.normal(0, 1, (2, H)), np.zeros(H)
W2, b2 = rng.normal(0, 1 / np.sqrt(H), (H, 1)), np.zeros(1)
sigmoid = lambda z: 1 / (1 + np.exp(-z))
lr = 0.5


def forward(X):
    h = np.tanh(X @ W1 + b1)
    return h, sigmoid(h @ W2 + b2).ravel()


for epoch in range(2001):
    h, p = forward(X[train])
    loss = -np.mean(y[train] * np.log(p + 1e-12) + (1 - y[train]) * np.log(1 - p + 1e-12))   # cross-entropy
    dz = (p - y[train])[:, None] / len(train)          # gradient of the loss at the output
    dW2, db2 = h.T @ dz, dz.sum(0)
    dh = dz @ W2.T * (1 - h ** 2)                       # backpropagate through tanh
    dW1, db1 = X[train].T @ dh, dh.sum(0)
    W1 -= lr * dW1; b1 -= lr * db1; W2 -= lr * dW2; b2 -= lr * db2
    if epoch % 500 == 0:
        acc = lambda s: np.mean((forward(X[s])[1] > 0.5) == y[s])
        print(f"epoch {epoch:4d}: loss {loss:.3f}, train accuracy {acc(train):.1%}, test accuracy {acc(test):.1%}")

relu = lambda z: np.maximum(0, z)
leaky = lambda z, a=0.2: np.where(z > 0, z, a * z)
print("ReLU(-2), ReLU(3):", relu(-2.0), relu(3.0), "  LeakyReLU(-2), LeakyReLU(3):", leaky(-2.0), leaky(3.0))

# The convex hull as a pointer sequence (Section 11.9, Figures 11.11 and 11.19)
import math
import random

rng = random.Random(4)
P = [(rng.random(), rng.random()) for _ in range(12)]


def cross(o, a, b):
    return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0])


def jarvis(P):
    """Gift wrapping: start at the leftmost point and keep turning to the most clockwise point."""
    start = min(range(len(P)), key=lambda i: P[i])
    hull, cur = [], start
    while True:
        hull.append(cur)
        nxt = (cur + 1) % len(P)
        for j in range(len(P)):
            if cross(P[cur], P[nxt], P[j]) < 0:
                nxt = j
        cur = nxt
        if cur == start:
            return hull


def graham(P):
    """Graham scan: sort by angle around the lowest point, then keep only left turns."""
    o = min(range(len(P)), key=lambda i: (P[i][1], P[i][0]))
    rest = sorted((i for i in range(len(P)) if i != o), key=lambda i: math.atan2(P[i][1] - P[o][1], P[i][0] - P[o][0]))
    st = [o]
    for i in rest:
        while len(st) > 1 and cross(P[st[-2]], P[st[-1]], P[i]) <= 0:
            st.pop()
        st.append(i)
    return st


def area(idx):
    pts = [P[i] for i in idx]
    return abs(sum(pts[i][0] * pts[i - 1][1] - pts[i - 1][0] * pts[i][1] for i in range(len(pts)))) / 2


h1, h2 = jarvis(P), graham(P)
print("Jarvis march hull:", [i + 1 for i in h1])
print("Graham scan hull: ", [i + 1 for i in h2], f"(the same {len(h2)} points, area {area(h2):.3f})")
# A pointer network outputs this sequence one index at a time: at step i, a softmax over the inputs

# The end-to-end pipeline of Figure 11.16 on a small TSP: edge probabilities, then greedy or beam-search decoding
import math
import random
from itertools import combinations

rng = random.Random(2)
n = 10
P = [(rng.random(), rng.random()) for _ in range(n)]
D = [[math.dist(a, b) for b in P] for a in P]
tour_len = lambda t: sum(D[t[i]][t[(i + 1) % n]] for i in range(n))

# Stand-in for the trained GNN's "predict" step: edge scores from distances (a k-nearest-neighbor softmax).
# A real model learns these probabilities from Concorde's optimal tours.
prob = [[0.0] * n for _ in range(n)]
for i in range(n):
    near = sorted((j for j in range(n) if j != i), key=lambda j: D[i][j])[:4]
    z = [math.exp(-D[i][j] / 0.1) for j in near]
    for j, w in zip(near, z):
        prob[i][j] = w / sum(z)


def beam_search(width):
    beams = [([0], 0.0)]
    for _ in range(n - 1):
        cand = [(t + [j], s + math.log(prob[t[-1]][j] + 1e-9)) for t, s in beams for j in range(n) if j not in t]
        beams = sorted(cand, key=lambda c: -c[1])[:width]
    return min((t for t, _ in beams), key=tour_len)            # pick the shortest of the surviving tours


def held_karp():
    """Exact dynamic programming, O(2^n n^2): the ground truth (Concorde's role in the book)."""
    best = {(1 << j, j): (D[0][j], [0, j]) for j in range(1, n)}
    for size in range(2, n):
        for sub in combinations(range(1, n), size):
            mask = sum(1 << j for j in sub)
            for j in sub:
                prev = mask ^ (1 << j)
                best[(mask, j)] = min(((best[(prev, k)][0] + D[k][j], best[(prev, k)][1] + [j]) for k in sub if k != j), key=lambda x: x[0])
    full = sum(1 << j for j in range(1, n))
    return min((best[(full, j)][0] + D[j][0], best[(full, j)][1]) for j in range(1, n))


opt, _ = held_karp()
for w in (1, 3, 10):
    print(f"beam width {w:2d} ({'greedy' if w == 1 else 'beam search'}): {tour_len(beam_search(w)):.4f}")
print(f"optimal (Held-Karp): {opt:.4f}")
# Amortized optimization (learning to optimize), a one-dimensional version of Listing 11.3 on the unit circle
import numpy as np

rng = np.random.default_rng(0)
K = 4                                               # components per function, as in c_convex(n_components=4)


def make_problem(rng):
    ys = rng.uniform(-np.pi, np.pi, K)              # component centers on the circle
    alphas = 0.7 * rng.random(K)                    # offsets in [0, 0.7)
    return np.concatenate([np.cos(ys), np.sin(ys), alphas])     # the parameter vector


def f(theta, p, gamma=0.5):
    """Soft-min of 0.5 d(theta, y_k)^2 + alpha_k, with d the arc (geodesic) distance."""
    ys = np.arctan2(p[K:2 * K], p[:K]); al = p[2 * K:]
    d = np.abs((theta - ys + np.pi) % (2 * np.pi) - np.pi)
    c = 0.5 * d ** 2 + al
    return -gamma * np.log(np.exp(-c / gamma).sum())


train = [make_problem(rng) for _ in range(64)]
test = [make_problem(rng) for _ in range(16)]
grid = np.linspace(-np.pi, np.pi, 2000)
solve = lambda p: grid[np.argmin([f(t, p) for t in grid])]     # the slow way: search every time

# model: parameters -> point on the circle, a small MLP whose 2 outputs are normalized like the sphere model
H = 64
W1 = rng.normal(0, 0.3, (3 * K, H)); W2 = rng.normal(0, 0.3, (H, 2)); lr = 0.01
for it in range(3000):
    p = train[rng.integers(len(train))]
    h = np.tanh(p @ W1); z = h @ W2; theta = np.arctan2(z[1], z[0])
    eps = 1e-4; g_theta = (f(theta + eps, p) - f(theta - eps, p)) / (2 * eps)   # loss = f(model(p)), as in the book
    r2 = z @ z; dz = g_theta * np.array([-z[1], z[0]]) / r2                      # d theta / d z
    dh = (W2 @ dz) * (1 - h ** 2)
    W2 -= lr * np.outer(h, dz); W1 -= lr * np.outer(p, dh)

pred = lambda p: (lambda z: np.arctan2(z[1], z[0]))(np.tanh(p @ W1) @ W2)
gap = lambda ps, guess: np.mean([f(guess(p), p) - f(solve(p), p) for p in ps])
print(f"mean gap f(prediction) - f(optimum), 0 is perfect:")
print(f"   trained problems {gap(train[:16], pred):.3f}, unseen problems {gap(test, pred):.3f}, random guess {gap(test, lambda p: rng.uniform(-np.pi, np.pi)):.3f}")
Part 9 · Summary

What to remember

Training is optimization

Backpropagation gives the gradient of the loss; a gradient method adjusts the weights.

Graphs

GCNs pass messages between neighbors; k layers see k hops, and a few labels can classify a whole network.

Attention and pointers

Attention weighs inputs by relevance; pointer networks use it to output positions in the input, fitting combinatorial problems.

Learned optimizers

End-to-end pipelines and amortized models trade training time for fast solutions to new instances.
